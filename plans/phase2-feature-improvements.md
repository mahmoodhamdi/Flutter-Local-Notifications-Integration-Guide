# المرحلة 2: تحسين الميزات الحالية

## الهدف
تحسين تجربة المستخدم وإضافة ميزات مفيدة للمشروع.

---

## المهام

### 1. عرض قائمة الإشعارات المجدولة
- إنشاء صفحة جديدة `PendingNotificationsPage`
- عرض جميع الإشعارات المجدولة
- إمكانية إلغاء إشعار محدد

### 2. إضافة إمكانية إلغاء إشعار محدد
- زر إلغاء لكل إشعار في القائمة
- تأكيد قبل الإلغاء

### 3. تحسين واجهة المستخدم
- إضافة أيقونات للأزرار
- تحسين التصميم العام
- إضافة animations

### 4. إضافة إشعار مع صورة كبيرة (Big Picture)
- دعم Big Picture style للإشعارات
- عرض صورة في الإشعار
